\# Infrastructure Health Monitor



A lightweight Python application for collecting local system resource metrics.



\## Implemented and Verified

\- CPU utilization

\- RAM utilization

\- Home drive disk utilization

\- Console-based reporting



\## Technologies

\- Python 3.14

\- psutil

\- Git

\- Windows PowerShell



\## Current Status

Initial resource collector implemented and successfully executed on a Windows laptop.



\## Future Improvements

\- Configurable alert thresholds

\- Structured logging

\- Service availability monitoring

\- Automated testing

\- Historical reporting
